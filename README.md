# Simulation

Консольная пошаговая симуляция экосистемы на Java. На карте живут травоядные и хищники: травоядные ищут и едят траву,
хищники охотятся на травоядных. Карта выводится в консоль эмодзи, ход симуляции запускается в автоматическом режиме,
пользователь может сделать паузу.

## Возможности

- Карта размером N×M (по умолчанию 30х10), размер настраивается.
- Два вида существ с разными характеристиками: травоядное и хищник.
- Поиск ближайшей цели и построение маршрута алгоритмом поиска в ширину (BFS) с обходом препятствий.
- Статические объекты: трава (еда), камни и деревья (препятствия).
- Автоматическое пополнение травы, травоядных и хищников в конце каждого хода.
- Консольное меню управления.

## Обитатели карты

| Иконка | Объект        | Описание                                                        |
|--------|---------------|-----------------------------------------------------------------|
| 🐰     | Травоядное    | HP 10, скорость 1 клетка за ход, сразу съедает траву            |
| 🐺     | Хищник        | HP 10, скорость 2 клетки за ход, урон 5. Охотится на травоядных |
| 🌱     | Трава         | Еда для травоядных                                              |
| 🪨     | Камень        | Непроходимое препятствие                                        |
| 🌳     | Дерево        | Непроходимое препятствие                                        |
| 🟫     | Пустая клетка | Свободная клетка карты                                          |

Перемещение возможно только по четырём направлениям (вверх, вниз, влево, вправо).

## Как это работает

**Инициализация.** Перед началом на карту случайно расставляются объекты. Количество зависит от настроек конфигурации в
файле `SimulationConfig`.

**Ход симуляции.** Каждый ход выполняются действия по порядку:

1. `MoveCreaturesAction` — каждое существо выбирает ближайшую цель своего типа (травоядное ищет траву, хищник ищет
   травоядное), строит путь через BFS и двигается на количество клеток, равное его скорости. Если цель оказалась рядом,
   существо взаимодействует с ней.
2. `ReplenishEntitiesAction` — восполняет существа до заданного в конфиге количества.

В начале каждого хода карта перерисовывается в консоли с паузой в 1 секунду.

## Требования

- JDK 25 или новее.
- Терминал с поддержкой UTF-8 и эмодзи.

## Управление

После запуска в консоли доступно меню. Введите цифру и нажмите Enter:

| Команда | Действие         |
|---------|------------------|
| `1`     | Начать симуляцию |
| `2`     | Выход            |

Во время выполнения симуляции можно нажать Enter для паузы.

## Настройка

Настройка размера карты, характеристик существ и их количества находится в `SimulationConfig`.
